# 🎓 Hệ thống quản lý học tập (.NET)

Website quản lý học tập được xây dựng bằng **ASP.NET Core**, hỗ trợ điểm danh GPS, phân quyền người dùng và lưu chứng chỉ bằng blockchain.

## 🚀 Chức năng chính

* Đăng nhập, đăng ký và phân quyền (Admin / Sinh viên)
* Điểm danh bằng GPS
* Quản lý điểm và lớp học
* Gửi email thông báo
* Lưu chứng chỉ bằng Blockchain
* Trang quản trị Admin

## 🛠 Công nghệ sử dụng

* ASP.NET Core MVC
* C#
* SQL Server
* Entity Framework
* HTML, CSS, JavaScript
* Bootstrap
